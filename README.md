## 🖱️ CyberMouse PRO - AI Optical Hand Tracking Virtual Mouse

Turn your webcam into a high-precision optical virtual mouse using MediaPipe hand tracking, low-latency filtering, and desktop OS cursor control.

### Features
- **Zero-Lag Optical Tracking**: Real-time hand landmark detection using MediaPipe.
- **Natural Gestures**: Point to move cursor, pinch to click, and customizable comfort zones.
- **Desktop Integration**: High-performance Win32 native bridge via Electron and C# mouse service.

### Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the application:
   ```bash
   npm start
   # or run start_desktop.bat
   ```

For detailed architecture and gesture mechanics, see [HOW_IT_WORKS.md](HOW_IT_WORKS.md).
